# Topic: gsupload

## Overview
Captures the end-to-end gsupload CLI workflow from config discovery through remote listing and uploading, plus the ignore pattern subsystem.

- Remote FTP/SFTP traversal (MLSd/NLST, BFS)
- Threaded uploads with directory caching
- Ignore file aggregation and pattern matching
